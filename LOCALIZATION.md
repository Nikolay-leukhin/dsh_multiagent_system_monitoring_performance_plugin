## Что пришлось переписать, а не перевести

Китайский в этом проекте — не только тексты, но и **правила разбора языка**. Дословный перевод
сломал бы функциональность, поэтому логика адаптирована под русский:

- `src/shared/aiplan.js`
  - `resolveDate()` — заново: «завтра», «послезавтра», «в следующую пятницу», «в эту пятницу»,
    «конец месяца», «3 ноября», «3.11», «+3 дня», «через 2 недели».
    Важная деталь: в JS `\w` не покрывает кириллицу, поэтому в шаблонах слов используются
    классы `[а-яё]`, а короткие дни недели («чт») матчатся только по границам слова — иначе
    «что» превращалось в «четверг».
  - `detectStatus()` — русские формулировки статусов.
  - `planFromRules()` — глаголы «добавь/удали/перенеси/закрой/запиши», извлечение названия задачи
    после маркера, разбор «ответственный: …».
  - `normalizeName()` — нормализация с русскими кавычками и пунктуацией.
- `src/shared/query.js` — набор регулярных выражений под русские вопросы; порядок веток сохранён
  (задачи раньше «просрочено», иначе «какие задачи просрочены» отвечало бы про проекты).
- `src/shared/insights.js` — `STATUS_TONE` теперь ключуется русскими статусами.
- `src/client/panel.js` — разделители тегов (`запятая`, `точка с запятой`, пробел).

## Пересборка и проверка

```bash
cd ph
npm install --no-save react react-dom        # только для рендер-тестов
node scripts/build-client.mjs                # src/ -> lib/client.js
node --test --test-isolation=none test/*.test.js
node scripts/check-workbench-package.mjs
npm pack --pack-destination ..               # dsh-workbench-project-console-1.0.3.tgz
```

Замечание по окружению: в песочнице `node --test` без `--test-isolation=none` падает на
`spawn EPERM` (нельзя открыть пайпы), поэтому тесты гоняются в одном процессе.

## Установка

```bash
# через инструмент плагинов DSH (так ставили здесь):
#   plugin_manager install_bundle -> dsh-workbench-project-console-1.0.3.tgz
# или вручную:
dsh plugin --profile web add "dsh-workbench-project-console-1.0.3.tgz"
```

После установки — перезапуск Harness (меню **Harness → Перезапустить**), иначе хост продолжает
отдавать старый клиентский бандл из памяти.

## Как откатиться на оригинал

```bash
dsh plugin --profile web remove dsh-workbench-project-console
# затем поставить 1.0.1 из GitHub Releases проекта
```
